# Cloudflare Workers Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy the existing Next.js 16 blog to Cloudflare Workers through OpenNext, using Cloudflare Images, R2-backed incremental caching, a Durable Object revalidation queue, and Cloudflare Web Analytics while preserving the current D1 and KV REST integrations.

**Architecture:** OpenNext builds the application into a Worker entry point and Workers Static Assets. Time-based Next.js revalidation uses an R2 incremental cache and a Durable Object queue; `next/image` uses the `IMAGES` binding. Vercel remains available as a rollback target until the Worker passes local, preview-domain, and production-domain verification.

**Tech Stack:** Next.js 16, React 19, TypeScript, pnpm, `@opennextjs/cloudflare`, Wrangler, Cloudflare Workers, Workers Static Assets, Cloudflare Images, R2, Durable Objects, Cloudflare Web Analytics

---

## File Map

- Modify `package.json`: add OpenNext dependencies and Cloudflare build, preview, deploy, and type-generation scripts; remove Vercel packages.
- Modify `pnpm-lock.yaml`: record dependency changes generated by pnpm.
- Create `open-next.config.ts`: select the R2 incremental cache and Durable Object queue.
- Create `wrangler.jsonc`: define the Worker, static assets, Images, R2, self-reference, Durable Object queue, observability, and runtime compatibility.
- Create `cloudflare-env.d.ts`: generated binding types from Wrangler.
- Modify `tsconfig.json`: include generated Cloudflare types if Wrangler does not add them automatically.
- Modify `src/app/layout.tsx`: remove Vercel Analytics and Speed Insights components.
- Modify `next.config.ts`: remove the global production cache header that can override route-specific and OpenNext cache behavior.
- Create `public/_headers`: preserve immutable caching for Next.js hashed static assets.
- Modify `.gitignore`: ignore `.open-next`, `.wrangler`, and local Wrangler state without altering unrelated user changes.
- Create `tests/cloudflare-migration.test.mjs`: configuration regression tests using Node's built-in test runner.
- Create `docs/cloudflare-deployment.md`: exact Cloudflare resource, secret, preview, custom-domain, Web Analytics, rollback, and verification procedure.
