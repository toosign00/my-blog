## 프로젝트 개요

Mobile Bookcase는 읽고 있는 책, 읽은 책, 읽고 싶은 책을 자연스럽게 관리하는 모바일 앱을 가정한 더미 프로젝트입니다.

## 개선 방향

책장 상태를 단순화하고, 사용자가 다음 행동을 빠르게 선택할 수 있도록 홈 화면의 정보 우선순위를 정리합니다.

## 테스트 관점

상태 변경, 검색, 정렬, 기록 삭제처럼 반복 사용되는 흐름을 중심으로 테스트 시나리오를 구성합니다.
