## 프로젝트 개요

Ops Dashboard는 서비스 운영에 필요한 지표, 알림, 작업 상태를 한곳에 모아보는 내부 도구를 가정한 더미 프로젝트입니다.

## 문제 정의

운영자는 여러 화면을 오가며 지표를 확인해야 했고, 알림의 우선순위를 판단하기 어려웠습니다.

## 접근 방식

- 상태를 정상, 주의, 조치 필요로 단순화합니다.
- 알림 목록과 관련 지표를 같은 화면에 배치합니다.
- 반복 확인 항목은 자동 새로고침 대신 명시적 갱신으로 제어합니다.
