## 프로젝트 개요

Project Atlas는 테스트 계획, 실행 현황, 결함 흐름을 하나의 업무 맥락에서 확인할 수 있도록 설계한 더미 프로젝트입니다.

## 핵심 목표

- QA 산출물을 프로젝트 단위로 빠르게 찾을 수 있게 구성합니다.
- 테스트 진행률과 남은 리스크를 한 화면에서 비교할 수 있게 만듭니다.
- 반복적으로 확인하는 링크와 문서를 카드 형태로 정리합니다.

## 맡은 역할

요구사항 정리, 정보구조 설계, 주요 화면 시나리오 정의를 담당했다는 가정으로 작성된 샘플 콘텐츠입니다.
